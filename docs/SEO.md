## Connecting a custom domain

1. **Buy the domain** (e.g. Namecheap, Cloudflare Registrar, Porkbun or Squarespace Domains). `.dev` domains are HTTPS-only, which Firebase handles automatically.
2. **Add it in Firebase:** [Firebase console](https://console.firebase.google.com/project/ntim-dev/hosting/sites) → Hosting → *Add custom domain*. Add both `yourdomain.dev` and `www.yourdomain.dev` (choose *Redirect* for `www` → apex).
3. **Add the DNS records** Firebase shows you (A/TXT records) at your registrar. Verification and the SSL certificate can take from a few minutes up to 24 hours.
4. **Point the site at it:** change `SITE_URL` in `astro.config.mjs`, then run:

   ```bash
   npm run og
   npm run build
   ```

   Commit (including the regenerated `public/og.png`), open a PR and merge. Canonical URLs, sitemap, robots.txt and social previews then all use the new domain.
5. **Update links elsewhere:** GitHub profile website, LinkedIn, X bio, app store developer pages.

The `ntim-dev.web.app` address keeps working after this; the canonical tags tell Google the custom domain is the real one.

## Google Search Console (after the domain is live)

1. Go to [Search Console](https://search.google.com/search-console) → *Add property* → **Domain** → enter the domain and add the TXT record it gives you at your registrar.
2. *Sitemaps* → submit `sitemap-index.xml`.
3. *URL inspection* → enter the home page URL → *Request indexing*. Repeat for `/archive`.
4. Optional: add the site to [Bing Webmaster Tools](https://www.bing.com/webmasters) using *Import from Google Search Console*.
