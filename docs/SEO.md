## Custom domain: kwakuntim.com

Registered at **Namecheap** (Sept 2026). The site code already uses it (`SITE_URL` in `astro.config.mjs`).

### 1. Connect it in Firebase
[Firebase console → Hosting](https://console.firebase.google.com/project/ntim-dev/hosting/sites) → site `ntim-dev` → **Add custom domain**:

1. Enter `kwakuntim.com` → Continue. Firebase shows the DNS records to add (a **TXT** record to verify ownership and one or more **A** records). Keep this screen open.
2. Add a second custom domain `www.kwakuntim.com` and choose **Redirect to** `kwakuntim.com`, so there's one canonical address.

### 2. Add the records in Namecheap
Namecheap → Domain List → `kwakuntim.com` → **Manage** → **Advanced DNS** → *Host records*:

| Type | Host | Value | Notes |
| --- | --- | --- | --- |
| A Record | `@` | the IP Firebase shows (typically `199.36.158.100`) | apex / `kwakuntim.com` |
| TXT Record | `@` | the `hosting-site=…` value Firebase shows | ownership verification |
| A Record or CNAME | `www` | exactly what Firebase shows for `www` | replace the existing `www → ntim-dev.web.app` CNAME if Firebase asks for something different |

Delete Namecheap's default **URL Redirect** / parking records for `@` and `www` if they're present — they conflict with Firebase. Always copy values from the Firebase screen rather than this table; Firebase's instructions win.

### 3. Wait for verification + SSL
Firebase shows *Pending* → *Needs setup* → **Connected**. DNS usually propagates in minutes on Namecheap, but the SSL certificate can take up to 24 hours. Check with:

```bash
dig +short A kwakuntim.com
curl -I https://kwakuntim.com
```

### 4. Merge the SEO PR
Once `https://kwakuntim.com` loads with a valid certificate, merge the PR so canonical URLs, sitemap, robots.txt and social previews go live on the new domain.

### 5. Update links elsewhere
GitHub profile website + profile README, LinkedIn, X bio, app store developer pages.

`ntim-dev.web.app` keeps working afterwards; canonical tags tell Google `kwakuntim.com` is the real address.

## Google Search Console (after kwakuntim.com is live)

1. Go to [Search Console](https://search.google.com/search-console) → *Add property* → **Domain** → enter `kwakuntim.com` and add the TXT record it gives you in Namecheap → Advanced DNS (it can sit alongside Firebase's TXT record).
2. *Sitemaps* → submit `sitemap-index.xml`.
3. *URL inspection* → enter the home page URL → *Request indexing*. Repeat for `/archive`.
4. Optional: add the site to [Bing Webmaster Tools](https://www.bing.com/webmasters) using *Import from Google Search Console*.
