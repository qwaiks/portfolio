# Project thumbnails

1200×675 cards, exported to WebP (~1000px wide) for the Projects section.

| File | Built from |
| --- | --- |
| `tikfinity.webp` | TikFinity Mobile App Store icon + two App Store screenshots |
| `asiaflare-latinflare.webp` | AsiaFlare cover photo + AsiaFlare and LatinFlare logos (from their sites) |
| `mybestpic.webp` | MyBestPic logo (from mybestpic.com) |
| `tripoclock.webp` | Trip o'clock App Store icon + two App Store screenshots |
| `oben-health.webp` | Screenshot of joinoben.com |
| `wacommunicate.webp` | Drawn from scratch — the app's store listings and website are all offline |

These use brand assets belonging to the apps' owners, shown here as portfolio work samples.
Replace any of them by dropping a 16:9 image in this folder and updating `image:` in `src/data/profile.ts`.
